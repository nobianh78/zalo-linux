# Workflow & Communication Rules

- **Zero-junk policy**: Tuyệt đối không tạo file rác, file test linh tinh, scratch file hay temp file bừa bãi trong repo. Nếu cần test, chạy inline hoặc tự động cleanup ngay.
- **Concise communication**: Trả lời ngắn gọn, tập trung vào code, kết quả và hành động kế tiếp. Không nói dài dòng.
